# Roadmap

- Offline PWA for the itinerary of the running trip
- Notifications (ntfy/Apprise): check-in tomorrow, flight in 3 h, over budget
- Shared read-only link for a trip (companions without an account)
- Recurring/favourite places across trips ("been here before")
- Pocket Split integration: who paid what on the trip
- PDF trip booklet (itinerary + bookings + map)
- Public transport / driving directions between consecutive places (OSRM)
